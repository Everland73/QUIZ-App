선생님 모드의 전체 흐름을 **순서대로** 실행합니다. 폴더는 `$1`, `$2`가 `report`이면 마지막에 보고서 파일도 저장합니다. `$1`이 없거나 `$2`가 비어 있지 않은데 `report`가 아니면 사용법(`/teacher-mode <폴더> [report]`)을 안내하고 멈추세요.

## 공통 규칙

- 각 단계의 명령 파일을 **직접 읽고** 그 규칙대로 수행하세요(기억에 의존 금지). 단계는 건너뛰거나 순서를 바꾸지 마세요.
- 앞 단계가 통과 조건을 못 지키면 **즉시 중단**하고 아래 "중단 보고"를 하세요. 실패를 숨기지 마세요.
- 모든 단계는 읽기 전용입니다(보고서 저장 단계만 새 파일을 만듭니다). 학생 이름·성적은 외부로 보내지 마세요.

## 단계

| 단계 | 따를 명령 | 통과 조건 |
|---|---|---|
| 1. 기록 점검 | `.claude/commands/teacher-collect.md` (`$1`) | 정상 파일 1개 이상, 기록 있는 학생 1명 이상 |
| 2. 학급 개요 | `.claude/commands/teacher-overview.md` (`$1`, 정렬 기본값) | 표 작성 완료 |
| 3. 학생 비교 | `.claude/commands/teacher-compare.md` (`$1`, 모드·학생은 생략) | 순위표·카테고리표 작성 |
| 4. 약점 분석 | `.claude/commands/teacher-weak.md` (`$1`, 기준 60) | 취약 카테고리 판단(또는 표본 부족 명시) |
| 5. 보고서 저장 | `.claude/commands/teacher-report.md` (`$1`) — **`$2`가 `report`일 때만** | 파일 저장·재확인 완료 |

- 단계마다 폴더를 다시 불러오지 말고, 1단계의 로더와 결과를 재사용하세요.
- 개별 학생을 더 보고 싶으면 마지막에 `/teacher-student <폴더> <이름>`을 안내하세요.

## 최종 보고

### 실행 요약
| 단계 | 결과 | 비고 |
|---|---|---|
| 1~4(+5) | ✅/❌/건너뜀 | |

그다음 핵심만 정리합니다: 불러온 학생 수와 제외된 파일, 학급 정답률, 모드별 상위권, 취약 카테고리, 도움이 필요한 학생(있으면), 저장한 보고서 경로(있으면), 데이터 한계.

## 중단 보고

- **실패한 단계**: 번호와 이름
- **실패한 조건**: 오류 메시지를 그대로 인용
- **이미 끝난 단계**: 통과한 단계
- **다음 조치 제안**: 필요한 파일 준비 방법(`/quiz-stats export`) 또는 재실행 방법
