`questions.js`에 새 퀴즈 문제를 1개 추가하세요.

- 카테고리: `$1`
- 난이도: `$2`

## 인자 확인

- `$1`은 기존 카테고리 중 하나여야 합니다. 현재 카테고리는 `한국사`, `세계지리`, `과학`, `예술과 문화`입니다. 파일을 읽어 실제 사용 중인 카테고리 값을 확인하세요.
- `$2`는 `easy`, `medium`, `hard` 중 하나여야 합니다. 한글(쉬움/보통/어려움)로 입력되면 영문 값으로 바꿔 처리하세요.
- 둘 중 하나라도 없거나 유효하지 않으면 사용법(`/quiz-add <카테고리> <난이도>`)과 가능한 값을 안내하고 멈추세요.
- 새 카테고리를 만들고 싶다는 요청이 명확하지 않다면, 목록에 없는 카테고리는 만들지 말고 확인을 받으세요.

## 작성 절차

1. `questions.js` 전체를 읽고 다음을 파악합니다.
   - 사용 중인 `id`의 최댓값 (새 `id`는 최댓값 + 1). `id`는 파일 위치와 무관하므로 전체에서 찾으세요.
   - 같은 카테고리에 이미 있는 문제들 (주제·정답이 겹치지 않게 하기 위함).
   - 전체 정답 위치(0~3) 분포.
2. 새 문제를 설계합니다.
   - 같은 카테고리·난이도의 기존 문제와 수준을 맞춥니다. 난이도 기준: easy는 상식 수준, medium은 학교에서 배우는 수준, hard는 구체적인 사실이나 구분이 필요한 수준입니다.
   - 기존 문제와 같은 질문이나 같은 정답을 쓰지 않습니다.
   - 오답 보기는 그럴듯하되 명백히 틀린 것이어야 합니다.
3. 정답 위치(`correctAnswer`)는 지금까지 가장 적게 쓰인 번호(0~3) 중에서 고릅니다. 보기 배열에서 정답을 그 위치에 놓으세요.
4. 아래 검증 가이드라인을 점검한 뒤 파일에 추가합니다.

## 검증 가이드라인 (반드시 준수)

CLAUDE.md의 "퀴즈 문제 교차 검증 가이드라인"을 따릅니다. 작성한 문제가 모두 통과해야 추가할 수 있습니다.

1. **정답이 하나뿐인가?** 다른 해석이 가능하면 문제 문장에 조건을 명시합니다. (예: 면적 기준, 2024년 기준)
2. **최상급 표현에 기준이 있는가?** '가장', '최초의', '최대' 등을 쓰면 문제 문장에 측정 기준을 넣습니다. 해설에만 기준을 쓰지 마세요.
3. **시간과 범위가 명확한가?** 시간이 지나면 변할 수 있는 정보는 시점을 적고, 지리적·분류적 범위를 한정합니다.
4. **교차 검증했는가?** 의심스러운 정보는 2개 이상의 출처로 확인합니다. 논란이 있는 내용은 주류 학설을 기준으로 하고 해설에 그 점을 밝힙니다. 출처를 확인할 수 없는 정보는 문제로 쓰지 말고 다른 주제를 고르세요.

확신이 낮은 사실(정확한 수치, 연도, 순위 등)은 WebSearch로 확인하세요. 검증하지 못했다면 그 사실을 문제에 쓰지 마세요.

## 형식

기존 문제와 완전히 같은 형식과 들여쓰기(4칸)로 추가합니다.

```js
    {
        id: <새 id>,
        category: "<카테고리>",
        difficulty: "<난이도>",
        question: "<문제>",
        options: ["<보기1>", "<보기2>", "<보기3>", "<보기4>"],
        correctAnswer: <0~3>,
        explanation: "<해설>"
    }
```

- `options`는 정확히 4개입니다.
- `explanation`은 정답의 근거를 한두 문장으로 쓰고, 기준이나 예외가 있으면 괄호로 덧붙입니다.
- 문자열은 큰따옴표를 씁니다. 문제 안의 따옴표는 작은따옴표(`'`)로 씁니다.
- 파일 끝의 `];`와 배열 문법(쉼표, 중괄호)이 깨지지 않게 하세요. 새 문제는 해당 카테고리 구간의 끝에 넣는 것이 좋지만, 구간 끝 위치가 모호하면 배열 맨 끝에 추가해도 됩니다. `id`로 구분하므로 위치는 동작에 영향이 없습니다.
- 파일 맨 위 카테고리 주석의 문제 수(예: `// 한국사 (13문제)`)가 있으면 실제 수와 맞도록 갱신합니다.

## 추가 후 확인

파일을 수정한 뒤 다음을 확인하세요.

1. `node -e "require('fs'); const s=require('fs').readFileSync('questions.js','utf8'); new Function(s+'; return quizQuestions;')()"` 등으로 문법 오류가 없는지 확인합니다.
2. `id`가 중복되지 않는지 확인합니다.
