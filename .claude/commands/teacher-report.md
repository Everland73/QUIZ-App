학급 성적을 **저장 가능한 보고서 파일**로 만듭니다. 폴더는 `$1`, 저장 폴더는 `$2`(기본 `teacher-reports/`)입니다. `$1`이 없으면 사용법을 안내하고 멈추세요.

## 절차

1. `.claude/commands/teacher-collect.md`의 공통 로더로 학생을 불러옵니다. 정상 학생이 없으면 중단하세요.
2. 아래 3개 명령의 **분석 규칙을 읽고 그대로 적용**해 내용을 만드세요(각 파일의 주의 사항 포함).
   - `.claude/commands/teacher-overview.md` → 학급 한눈에 표
   - `.claude/commands/teacher-compare.md` → 모드별 순위(기록이 가장 많은 모드)와 카테고리 비교표
   - `.claude/commands/teacher-weak.md` → 취약 카테고리와 도움이 필요한 학생(기준 60)
3. 저장 폴더가 없으면 만들고, `teacher-report-YYYYMMDD-HHMMSS.md`로 저장합니다. **기존 파일을 덮어쓰지 마세요.**
4. 저장한 파일을 다시 읽어 표가 깨지지 않았는지, 학생 수·기록 수가 로더 결과와 맞는지 확인하세요.

## 보고서 구성

제목·생성 시각·입력 폴더 → 불러온 학생과 제외된 파일 → 학급 한눈에 표 → 모드별 순위 → 카테고리 비교 → 취약점과 제안 → 데이터 한계(기록 보관 상한, 표본 적음, 내보낸 시점).

## 주의

- **이 보고서에는 학생 이름과 성적이 들어갑니다.** 저장 위치를 알리고, 공유 시 개인정보에 주의하라고 한 줄 안내하세요. Artifact 등으로 게시하지 마세요.
- 프로젝트 안에서는 보고서 파일 외에 아무것도 만들거나 수정하지 마세요. 학생 파일은 읽기 전용입니다.
- 커밋은 사용자가 요청할 때만 합니다.
